# Material 3 Figma Design Kit Archives

This directory stores the official Google Material 3 Design Kit assets and community exports gathered for Figma reference.

## Contents
- **Material 3 Design Kit (Community).zip / .png**: Master Figma kit slices, frames, and component variants.
- Slices include buttons, FABs, navigation items, shapes, toolbars, step indicators, dialogs, and component states.
- These assets can be opened in Figma or extracted as vector references.
